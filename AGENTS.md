# Agent Setup

## Goal

Build the smallest solid version of the HighAdvocacy testimonial assignment before adding optional features.

## Instructions Used

- Read `ASSIGNMENT.md` and `JOURNAL_TEMPLATE.md` before coding.
- Prioritize the tested P0 path: submit testimonial, review pending item, approve it, and show it on the public wall.
- Use a simple two-folder structure: `client` for React and `server` for Node.js.
- Prefer understandable code over clever abstractions because the follow-up interview will ask about implementation details.
- Keep optional features small and clearly documented.
- Update `JOURNAL.md` honestly while working.

## Review Checklist

- Rejected testimonials must never appear on the public wall or widget API.
- The app must run locally without paid services.
- README must explain setup, completed scope, skipped scope, and verification steps.
